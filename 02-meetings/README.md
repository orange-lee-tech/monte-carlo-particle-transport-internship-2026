# 组会会议记录

本目录用于长期管理实习期间的组会记录。预计每周召开1—2次，总量超过10次，因此按日期独立建档。

## 命名规则

```text
YYYY-MM-DD-group-meeting-NN.md
```

- 日期以实际会议日期为准；
- 同日多次会议使用递增编号；
- 原始TXT、语音转写或聊天摘要应整理为Markdown后再入库；
- 不将不确定信息补写成事实；
- 人名、任务、数值和单位应尽量保留原始表述；
- 待办事项应注明责任人和后续动作；
- 与个人实习主线直接相关的事项，可在当日日志中简要引用，但不重复整篇会议记录。

## 建议结构

1. 会议信息；
2. 议题与进展；
3. 形成的结论；
4. 待办事项；
5. 与本人当前工作的关系；
6. 待确认信息。
