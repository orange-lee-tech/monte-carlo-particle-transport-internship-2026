# 03-notes：基础知识笔记

本目录用于整理实习期间的理论学习笔记。建议先从“够用的概念框架”入手，不必一开始追求完整推导。

## 子目录说明

- `monte-carlo/`：蒙特卡洛方法、随机抽样、统计误差等。
- `particle-transport/`：粒子输运、核科学基础、截面、散射、吸收、剂量等。
- `thermal-fluid/`：能源动力、传热、流体力学、CFD 与 Ansys/Fluent 基础。

## 学习策略

1. 先建立物理图景；
2. 再整理核心概念；
3. 最后补公式、推导和软件实现方式。

## 推荐笔记结构

每个知识点建议按以下结构记录：

- 这个概念解决什么问题？
- 它在粒子输运或热工仿真中有什么用？
- 最简数学表达是什么？
- 软件中如何体现？
- 我目前哪里还不懂？
