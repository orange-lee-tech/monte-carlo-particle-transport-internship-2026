# 热工流体与 CFD 基础

本目录用于整理能源动力、传热、流体力学和 CFD 软件学习相关知识。

1. 热量如何传递？
2. 流体为什么会产生速度场、压力场和温度场？

4. 什么是网格？网格质量为什么重要？
5. 什么是收敛？
