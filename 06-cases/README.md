# 06-cases：算例与结果分析

本目录用于保存软件学习过程中形成的算例记录，包括热工流体仿真案例和蒙特卡洛粒子输运案例。

## 子目录说明

- `ansys-cases/`：Ansys/Fluent/CFX 等热工流体或工程仿真案例。
- `mc-cases/`：蒙特卡洛粒子输运相关案例。

## 每个算例建议记录

1. 案例名称；
2. 计算目的；
3. 几何模型；
4. 材料或物性；
5. 边界条件或源项；
6. 网格或抽样设置；
7. 求解设置；
8. 结果图；
9. 误差、收敛或统计可靠性分析；
10. 我的理解与问题。

## 注意事项

不上传单位内部工程文件、涉密模型、未公开数据或受版权限制的商业软件案例文件。
