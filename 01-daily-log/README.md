# 01-daily-log：每日实习日志

本目录用于记录实习全过程日志。学校要求全过程记录实习日志，因此本目录是后续撰写实习报告和准备答辩 PPT 的核心材料来源。

## 建议记录频率

每天记录一次。内容不必很长，但要真实、连续、可追溯。

## 日志基本结构

建议每篇日志包含：

1. 今日任务
2. 今日学习/工作内容
3. 关键概念或软件操作记录
4. 遇到的问题
5. 解决过程或待解决问题
6. 明日计划
7. 可用于报告或 PPT 的素材

## 命名规范

使用日期命名：

```text
2026-07-06.md
2026-07-07.md
```

## 写作原则

先保证每天有记录，再追求整理质量。不要把日志写成流水账，要尽量留下“可复用信息”：概念解释、操作步骤、问题原因、结果截图说明、个人理解。
