# 01-daily-log：实习事实记录

本目录保存 2026 年生产实习的终版事实日志。现场实习已结束，现有每日日志原则上全部只读，不再用后来的认识倒写当日事实。

## 当前覆盖

实际存在工作日志的日期已全部保留；最后一篇现场日志为 `2026-08-27.md`。

`2026-08-03—08-07` 无工作日日志，不补写。

周度材料统一位于 `weekly-review/`，现有 7 篇有日志依据的自然周周报，以及 1 篇不对应自然周的技术路线与工程管理特别周刊。

## 使用方式

最终报告、答辩和交接需要某个具体数据或判断时，优先从周报定位，再回到对应每日终版日志核对证据。

## 写作与权限原则

- 只记录真实发生的工作；
- 区分事实、当时判断和待确认项；
- 不补写未发生的任务或未表达的情绪；
- 终版日志不因后续认识改变而重写，除非用户明确授权；
- 后续新增总结、报告和交接材料应进入 `07-reports/`、`08-presentation/` 或 `10-handoff/`，不再追加到历史日报。
