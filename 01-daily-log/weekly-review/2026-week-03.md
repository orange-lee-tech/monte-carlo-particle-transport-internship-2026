# 第3周周报（2026-07-20—2026-07-23）

## 本周完成

本周正式进入帅文文热工计算链继承阶段。通过完成论文第4章精读，建立了“束流与准直参数—FLUKA能量沉积—Python/UDF热源转换—Fluent温度与流场—Mechanical热应力—异常工况保护”的完整工程逻辑。当前工作的核心不是重新设计准直器，而是在已有模型基础上恢复接口、验证可信度并建立可扩展基线。

程序与数据方面，重构 FLUKA `.29` 到 Fluent 的数据接口，整理 input、output 和 udf 目录，升级 Python 转换程序，实现多工况读取、严格数据量检查及配套 `.c/.h` 生成。确认当前计分网格为20×20×28，共11200个数据点，并明确 `.29`、数组 `.c/.h`、UDF、libudf 和 Fluent case/data 之间的职责关系。

计算方面，针对原工程丢失的 UDF 主程序和动态库，重新建立 `ENERGY_PLAN` 热源函数，完成编译、加载及 source 铜区域挂接。体积积分得到 source 区功率约37.24 kW、全部区域约38.17 kW；Fluent 迭代后 source 最高温度约210 ℃，质量流量守恒，形成第一版可运行、可重启的工程基线。

7月23日组会中汇报了 ANSYS 学习、帅文文技术基线继承和 FLUKA—Fluent 热源耦合进展。会议进一步明确：继续推进 UDF 验证和论文结果对齐，并向老师确认后续是否需要系统学习 FLUKA 建模与计分流程。

## 当前问题与下周重点

当前仅证明软件链可运行，尚需核实 FLUKA 单位、5 mA依据、坐标映射、voxel—cell覆盖、整体能量守恒和论文锚点工况。下一周优先完成数据逐项验证、功率差异解释和热工结果回归，再决定工程拓展方向。
