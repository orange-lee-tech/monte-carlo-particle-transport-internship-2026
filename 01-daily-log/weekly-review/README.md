# 周计划与周总结

本目录与每日实习日志共同构成进度记录体系：

```text
每日事实记录
→ 周度归纳与偏差分析
→ 阶段报告和组会材料
```

周报重点回答：

1. 本周实际完成了什么；
2. 哪些结论已经验证，哪些仍是暂定假设；
3. 当前工程链推进到哪一步；
4. 下一周最重要的阻塞项是什么。

不重复堆砌每日日志，不要求固定发表感想。

## 编号与生成规则

- 周报按本次实习的自然周编号，周一至周五作为对应工作周范围；
- 只要该周在 `01-daily-log/` 中存在真实工作日志，就生成对应周报；
- 没有工作日日志的自然周不补写、不虚构内容，周次编号仍保留；
- 周报以日志事实为依据，后续认识只能用于纠正表述，不能把后来才得到的结论倒写成当周已完成事项。
