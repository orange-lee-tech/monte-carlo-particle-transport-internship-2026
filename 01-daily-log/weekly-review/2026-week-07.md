# 第7周周报（2026-08-17—2026-08-21）

## 本周完成

本周将工作明确拆分为 FLUKA 数据接口 A 线、正式 CAD/Fluent 几何 B 线，并穿插开展靶材料热物性实验。这样做的目的，是避免数据接口、几何拓扑和实验测量三个问题相互干扰：A 线只回答“FLUKA 数据是否完整、单位和功率是否正确”，B 线只回答“CAD 是否具备生成 CFD 流体域的拓扑条件”，实验线则独立评价热物性输入数据的可信度。

### A 线：新 FLUKA 数据接口闭环

对 `.30.lis` 的严格扫描确认：理论应有 **34,560,000** 个数据，文本文件实际只有 **14,786,930** 个完整数值，覆盖率仅 **42.786256%**，且未发现后续错误块或第二段有效数据。随后读取原始二进制 `target_4collimator001_fort.30`，文件大小约 **138.24 MB**，解析出 Fortran sequential record，其中主数据 record 恰好包含 **34,560,000 个 float32**，与 300×300×384 网格严格一致。进一步将 `.lis` 中已有文本值与二进制矩阵前缀逐项比较，未发现实质数值错位，因此可以确认：`.lis` 不是“另一套数据”，而是原始完整矩阵被截断后的 ASCII 前缀。

Python 与 Fluent UDF 分别独立解析 `fort.30`，对数据个数、矩阵总和、峰值位置、峰值大小及文件 Hash 的结果一致。矩阵中约 **24,247,850** 个位置非零、**10,312,150** 个位置为零。按 5 mA 归一化及 1 mm³ voxel 体积积分后，全域能量沉积功率为 **31.035322 kW**，峰值体热源约 **3.584×10⁷ W/m³**。因此正式数据路线被固定为：

```text
fort.30 原始二进制
→ Fortran record 解析
→ 34.56M float32
→ UDF static memory
→ 5 mA 归一化
→ 坐标映射
→ DEFINE_SOURCE
```

这里“数据读取—单位归一化—总功率”已经闭环，唯一尚未锁定的是 CAD↔FLUKA 三维坐标映射；在几何本身尚未稳定前，不提前把热源挂到正式模型上。

### B 线：Share Topology 问题追溯到 CAD 实体

几何线首先验证了继续调网格参数不能解决根因。STEP/`.x_t` 模型在 Share Topology 中反复出现 non-manifold、node insertion failed、dihedral/self-intersection 警告甚至 SIGSEGV；将局部尺寸从 1 mm 继续加密到 0.5 mm 后，表面单元规模增大到约 **631 万**，失败反而扩散，说明“网格不够细”不是充分解释。

SpaceClaim 横截面和布尔检查随后确认，部分铜体与冷却管存在真实体积穿模。针对一根空心管建立“两刀法”：先清除铜体与管壁的交叠，再清除铜体侵入 **Ø12 mm** 管腔的部分，从而恢复壁厚约 **1.5 mm**、外径约 **15 mm** 的独立流道结构。Local Join A/B 检验中，某局部接口从约 **7,254** 个 inter-zone intersection 降至约 **5,265** 个，但 self-intersection=0、duplicate=0，证明 Join 能整理部分表面，却无法替代上游实体拓扑修复。

更关键的发现是：若干螺旋空心冷却管与圆柱主体在 CAD 中已经被并为同一个连续 Solid，原本应作为“管壁—铜体”边界的内部界面被 Boolean 合并。这解释了为什么 Fluent 侧不断出现难以通过局部网格参数消除的接口异常。后续优先级由“继续 Mesh tuning”转为“先恢复独立管体，再重新生成共享界面”。

### 热物性实验支线

DRPL-V 平板热流计实验在 150/220/300/350 N 多个载荷下重复测试。补测后大多数重复组离散度明显下降，**12/15** 个重复工况的 CV 低于 1%，全部新数据的中位 CV 约 **0.137%**。早期部分“压力升高导致导热系数明显变化”的异常值没有被重复出来，在约 **76–179 kPa** 范围内没有形成稳定单调的压力规律。

相比之下，温度趋势更稳定：跨压力平均等效导热系数约由 **19.90 W/(m·K)**（平均温度约24.8 ℃）上升到 **21.95 W/(m·K)**（约59.3 ℃）。因此当前更稳妥的工程处理是使用封装结构厚度方向的 **K_eff(T)** 表格插值，而不是强行构造缺乏重复性支持的 `K=f(T,P)`。这里的 K 应理解为样品、封装和接触界面共同表现出的等效值，而不是某一种金属的本征导热率。

## 后续重点

下一步首先修复正式 CAD 中被合并或穿模的冷却管拓扑，确认 Surface Mesh 与 Share Topology 稳定后，再依次完成 Capping→流体域→Volume Mesh。只有新 Cell Zone 明确后，才能继续锁定 CAD↔FLUKA 坐标映射并正式挂接 UDF 热源。实验支线则以“重复性优先、绝对准确度另行验证”为原则，为后续热工模型提供有边界条件的 K_eff 数据，而不夸大为材料本征参数。
