# 07-reports：实习报告与阶段材料

本目录用于保存实习报告相关材料，包括报告提纲、阶段总结、图表素材和最终稿。

## 报告材料来源

最终实习报告主要来自以下目录：

- `01-daily-log/`：全过程日志；
- `02-weekly-review/`：周总结和阶段成果；
- `03-notes/`：理论基础；
- `04-literature/`：文献调研；
- `05-software/`：软件学习；
- `06-cases/`：算例与结果分析。

## 报告建议结构

1. 实习背景与任务；
2. 实习单位与实习安排概述；
3. 蒙特卡洛方法理论基础；
4. 粒子输运基础与软件调研；
5. Ansys/Fluent 或热工流体仿真学习；
6. 案例学习与结果分析；
7. 实习收获与不足；
8. 后续学习计划。

## 写作原则

实习报告要体现“过程真实、任务明确、学习有递进、成果可追溯”。不要只写空泛心得，要尽量引用日志、笔记、软件操作记录和案例结果。
