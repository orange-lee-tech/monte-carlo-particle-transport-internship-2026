# 07-reports：实习报告与阶段材料

本目录用于保存实习报告相关材料，包括报告提纲、阶段总结、图表素材和最终稿。

## 当前阶段材料

- `internship-content-review-by-technical-route.md`：截至 2026-08-27 的实习内容总盘点，按技术路线而非日期重组；作为后续最终报告/PPT的事实底稿。
- `internship-report-outline.md`：早期报告提纲，最终报告阶段可在总盘点基础上重新调整，不直接视为终稿结构。

## 报告材料来源

最终实习报告主要来自以下目录：

- `01-daily-log/`：全过程日志；
- `01-daily-log/weekly-review/`：周总结与阶段成果；
- `02-meetings/`：组会记录；
- `03-notes/`：理论基础；
- `04-literature/`：文献调研；
- `05-software/`：软件学习；
- `06-cases/`：算例与结果分析。

## 报告建议结构

1. 实习背景与任务；
2. 实习单位与实习安排概述；
3. 蒙特卡洛方法理论基础；
4. 粒子输运基础与软件调研；
5. Ansys/Fluent 或热工流体仿真学习；
6. 案例学习与结果分析；
7. 实习收获与不足；
8. 后续学习计划。

> 上述结构为早期建议。最终报告应优先依据技术路线总盘点重新组织“问题—方法—证据—成果—未完成项”。

## 写作原则

实习报告要体现“过程真实、任务明确、学习有递进、成果可追溯”。不要只写空泛心得，要尽量引用日志、周报、笔记、软件操作记录和案例结果。
