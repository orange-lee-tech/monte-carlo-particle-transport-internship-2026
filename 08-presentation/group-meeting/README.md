# 组会汇报记录

## 目录用途

本目录用于记录实习期间参加课题组组会的准备材料、发言稿、汇报提纲和视觉素材。

## 文件规范

- 发言稿统一使用 Markdown 格式。
- 图片、流程图等素材存放于 assets 目录。
- 推荐使用 Mermaid 绘制流程图。
- 命名格式：YYYY-MM-DD-topic.md

示例：

```text
2026-07-16-first-group-meeting.md
```

## 汇报原则

1. 不虚报成果，不将个人学习过程包装为课题组成果。
2. 当前阶段定位为：理解已有工作、建立知识体系、准备接手任务。
3. 汇报重点：
   - 已阅读资料；
   - 对问题背景的理解；
   - 当前疑问；
   - 下一步学习计划。

## 当前阶段说明

实习初期主要任务是消化已有研究资料，包括帅文文论文及相关文献，建立粒子输运、能量沉积、热结构分析之间的联系，为后续工作承接做准备。
