# 08-presentation：开学答辩 PPT 材料

本目录用于保存开学后自主实习 PPT 答辩相关材料，包括 PPT 提纲、讲稿、图表素材和展示逻辑。

## PPT 建议逻辑

PPT 不要简单罗列日志，而要讲清楚一条主线：

> 我为什么做这个实习？我做了什么？我学到了什么？我有什么阶段性成果？后续准备怎么继续？

## 推荐结构

1. 实习基本情况
2. 实习任务与 8 周计划
3. 蒙特卡洛粒子输运方向学习
4. 现有软件调研与使用
5. Ansys/Fluent 与热工流体方向拓展
6. 案例学习或操作记录
7. 实习收获与问题反思
8. 后续学习计划

## 素材来源

- 每日实习日志
- 每周总结
- 软件截图
- 案例结果图
- 文献阅读表
- 术语框架图
- 实习报告中的图表和总结段落
