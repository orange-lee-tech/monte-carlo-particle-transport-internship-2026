# 08-presentation：开学答辩 PPT 材料

本目录用于保存开学后自主实习 PPT 答辩相关材料，包括 PPT 提纲、讲稿、图表素材和展示逻辑。

## 当前主文件

- `final-internship-ppt-outline.md`：最终实习汇报的信息架构，采用“多图少字”原则，以能力演进和关键证据为主线，并给出每页视觉、数据和口头信息锚点。

## 当前 PPT 主线

PPT 不复述最终报告正文，而是通过可视化证据讲清楚：

```text
我处在科研链条的什么位置
→ 能力如何变化
→ 哪些关键事实改变了我的判断
→ 如何从软件报错追到系统根因
→ AI/GitHub如何提高效率又接受验证约束
→ 下一步还缺什么
```

推荐结构为 9 页正文 + 1 页备用证据：

1. 封面；
2. 科研链条与本人职责边界；
3. 从软件操作到工程接手；
4. 18.422%功率缺口：模型能跑不等于结果可信；
5. fort.30完整性验证：输入文件也需要审查；
6. CAD/Fluent根因诊断：故障在下游，根因可能在上游；
7. DRPL-V：从测K到评价测量系统；
8. AI + GitHub：效率与约束；
9. 能力变化、局限与未来；
10. 备用证据页。

## 展示原则

- 每页只保留 1 个核心判断；
- 每页优先 1～2 张主图 + 1 组关键数字；
- 不把 Markdown 正文复制到 PPT；
- 软件截图只在能证明判断时使用；
- 优先展示“证据如何推翻/确认原判断”的过程图；
- 复杂技术细节放入备用证据页，主讲流保持清晰。
