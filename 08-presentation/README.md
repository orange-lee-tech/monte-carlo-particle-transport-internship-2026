## 展示原则

- 每页只保留 1 个核心判断；
- 优先 1～2 张主图 + 1 组关键数字；
- 不复制最终报告长段文字；
- 软件截图只有在能承担“证据”作用时才进入主讲页；
- 未完成项与证据边界必须和成果同样清楚。
