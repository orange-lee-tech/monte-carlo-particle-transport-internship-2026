## 使用原则

- **原始文件已入库** ≠ 已读；
- **机器辅助笔记完成** ≠ 用户已内化；
- **论文事实**、**用户理解**、**工程验证**、**待核实项**必须分开；
- 外部装置参数只用于量级检查、方法借鉴和风险预警，不直接替代本项目计算；
- 最终报告和答辩若引用具体技术结论，应能回到原始文献或工程验证记录。
