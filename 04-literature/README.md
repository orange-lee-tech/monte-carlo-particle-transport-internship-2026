## 状态区分

- **原始文件已入库**：文件存在，不代表已读；
- **机器辅助笔记已形成**：已提取结构和工程信息，不代表用户已内化；
- **用户人工精读**：用户已阅读并形成可复述理解；
- **已进入工程继承**：论文内容已与代码、模型和验证记录建立对应；
- **已用于独立拓展**：相关方法已进入新方案或新工况设计。

外部文献中的参数只作为量级参考、方法借鉴和风险预告，不直接替代当前设备计算。
