# 04-literature：文献与资料管理

本目录用于保存文献清单、阅读笔记和资料摘录。

## 建议管理方式

- `reading-list.md`：统一记录待读、在读、已读资料。
- `paper-notes/`：保存单篇论文或资料的阅读笔记。
- 不建议直接上传大量版权受限 PDF，优先记录题名、作者、来源、链接和个人笔记。

## 阅读笔记建议结构

1. 文献基本信息
2. 研究对象
3. 使用的方法
4. 主要结论
5. 与本实习主题的关系
6. 我目前看不懂的地方
7. 可用于报告/PPT的内容

## 当前优先阅读方向

- 蒙特卡洛方法入门资料
- 粒子输运基础资料
- 常见蒙特卡洛粒子输运软件介绍
- Ansys Fluent 入门教程或官方文档
- 热工流体仿真基础案例
