## 使用原则

- 论文明确报告的结果写为“论文结果”；
- 代码和Fluent运行得到的结果写为“当前实现结果”；
- 两者工况不一致时不得直接比较；
- 未核实的单位、束流强度和映射关系保留为待确认项；
- 完成基线继承后，再用外部文献支持开创性拓展。
