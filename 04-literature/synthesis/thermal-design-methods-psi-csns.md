# 专题综合｜高功率束流部件热设计的四条工程主线

更新时间：2026-07-10

关联文献：

- `LIT-003`：PSI KHE2/KHE3 高功率准直器；
- `LIT-004`：CSNS/RCS 可调式次级准直器吸收体；
- `LIT-005`：PSI MHC5 电流监测器；
- `LIT-006`：CAFe 200 kW 连续波质子束流终止器。

## 1. 核心结论

四篇文献说明，“束流部件热设计”不能按统一模板展开。首先要判断设备由什么矛盾主导：

| 工程主线 | 典型设备 | 优先解决的问题 |
|---|---|---|
| 重塑能量沉积分布 | PSI百千瓦级固定准直器 | 改孔型、分配沉积功率、控制下游束损 |
| 协调辐射与机械边界 | CSNS约500 W可调吸收挡块 | 屏蔽、真空运动、空气/水活化、温控策略 |
| 校核冷却模型和失效裕度 | PSI数百瓦MHC5监测器 | 实验校核CFD、确定流速拐点、断水被动安全 |
| 建立完整工程闭环 | CAFe 200 kW beam dump | 束斑整形、锥面摊功率、水冷、热结构、维护和分级运行验证 |

总体顺序应是：

> 明确束流功能与热负荷尺度 → 控制局部功率密度 → 选择材料和冷却 → 校核温度/应力/变形 → 处理活化与维护 → 分级运行验证。

## 2. 四条互补设计路线

### 2.1 从束流物理端降低热负荷

PSI准直器表明，扩大孔径约12.5%可降低准直器自身沉积功率和峰值温度，但孔径过大会导致束流直接损失在下游四极磁铁上。

进一步优化使用收敛—发散孔型，使KHE3后部材料也参与吸收，从而改善KHE2/KHE3功率分配。

适用于：

- 设备直接拦截高功率束流；
- 热点主要由空间沉积分布决定；
- 单靠提高换热系数难以获得足够裕度。

### 2.2 从工程边界端选择冷却方式

CSNS吸收体表明，纯热工上可行的强制风冷可能因活化空气排放被否决；水路继续靠近束流区虽然可降温，但当收益趋缓后会增加水活化和维护负担。

适用于：

- 设备需要真空运动和精准定位；
- 周围存在厚屏蔽和狭小空间；
- 冷却介质可能成为放射性输运通道。

### 2.3 从验证与事故端增加可信度

PSI MHC5通过80→30 ℃冷却实验测定时间常数，用实验校核CFD，并明确模型在低流速区误差增大。

其10 mm水管在约0.4 m/s进入充分湍流，2 m/s后继续提速收益很小。断水时采用高发射率表面降低辐射平衡温度，形成主动水冷之外的被动安全层。

适用于：

- 冷却边界不确定性可能主导温度预测；
- 需要确定流速收益拐点；
- 需要评估主动冷却失效后的处置时间。

### 2.4 从总体系统端完成工程落地

CAFe 200 kW beam dump采用1.2 m长锥面、300 mm口径和约32 mm RMS束斑，将峰值功率密度控制在182 W/cm²。夹层水速约6–10.6 m/s，ANSYS预测水侧/束流侧最高温度为93/150 ℃，最大应力117 MPa、变形1.18 mm。

更重要的是，该装置经过低占空比定位、逐级升功率和连续波运行，最终实现200 kW、306 h CW和2049 mAh累计运行。

适用于：

- 需要吸收全部高功率束流；
- 需要把束流光学、前置准直、吸收体和监测系统联合设计；
- 需要从仿真走向制造、安装、维护和运行验证。

## 3. 对当前方案的通用检查表

### 束流与热源

- 总沉积功率及三维分布是否由完整束线模型得到？
- 是否通过束斑、入射角、孔型或多级结构扩大有效受热面积？
- 热点位置是否随束流位置和角度偏差显著变化？
- 前置准直器能否限制异常束晕并监测截获功率？

### 冷却

- 当前流速是否进入稳定湍流区？
- 是否存在明显的换热收益拐点？
- 流量、流速、压降、水温升和局部壁温是否同时闭合？
- 高流速引起的冲蚀、振动、腐蚀和泵功是否可接受？
- 冷却水活化及回路屏蔽是否纳入系统模型？

### 温度、应力与变形

- 峰值温度是否低于明确的材料或功能限值？
- 水侧壁温是否具有足够的沸腾裕度？
- 应力是否与温度相关屈服强度比较？
- 变形是否影响有效孔径、束流入射角或流道间隙？
- 是否分析束流偏心、束斑缩小、启停循环等工况？

### 材料与制造

- 材料参数是否对应钎焊、退火、焊接后的真实状态？
- 是否同时考虑导热、强度、活化、腐蚀和加工？
- 是否考虑辐照后性能变化和寿命？

### 验证、保护与维护

- CFD是否用时间常数、压降、温升或表面温度实验校核？
- 是否制定低占空比到额定功率的分级验证流程？
- 温度、束损、流量和压差监测如何参与联锁？
- 是否预先设计远程拆装、屏蔽塞、管路断开和更换路径？

## 4. 组内分享主线

建议不要逐篇汇报，而用四个问题串联：

1. **热源太集中怎么办？**——PSI准直器：先改孔型和功率分配。
2. **冷却方式怎么选？**——CSNS吸收体：同时考虑屏蔽、活化、真空和维护。
3. **仿真怎么证明可信？**——PSI MHC5：用瞬态实验校核CFD。
4. **怎样真正做到200 kW运行？**——CAFe beam dump：束流整形、锥面水冷、热结构校核、远程维护和分级升功率形成闭环。

一句话总结：

> 高可靠束流部件不是“算出温度低于限值”就结束，而是要证明热源、边界、材料和结构可信，并通过可控的分级运行验证。
