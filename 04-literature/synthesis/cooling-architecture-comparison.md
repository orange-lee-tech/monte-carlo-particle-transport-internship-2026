# 专题综合｜准直与吸收结构冷却架构比较

更新时间：2026-07-10

关联文献：

- `LIT-004`：CSNS/RCS 可调式次级准直器吸收体；
- `LIT-006`：CAFe 200 kW 连续波束流终止器；
- `LIT-007`：CERN TCTP 准直器；
- `LIT-008`：SNS 双壁准直吸收器。

## 1. 为什么需要按“架构”比较

高功率束流部件的水冷不能只比较流速或换热系数。不同方案中，热量从束流沉积区到冷却水之间经过的结构层次不同，因而控制问题也不同。

应先画清：

> 热源 → 吸收材料 → 连接/界面 → 冷却边界 → 水回路

再判断主要热阻、失效模式和监测手段。

## 2. 四类代表性架构

| 架构 | 代表文献 | 主要传热路径 | 冷却位置 | 主要优势 | 主要风险 |
|---|---|---|---|---|---|
| 远端导热冷却 | CSNS LIT-004 | 铜挡块→导热构件→外部散热片/水管 | 热源区之外 | 适应真空运动机构，水路远离束流 | 导热路径长，温度和定位受结构热阻控制 |
| 外置冷却管 | CERN LIT-007 | 吸收块→Glidcop→接触界面→CuNi管→水 | 主体背面外置管 | 管路独立、可钎焊或拆装 | 接触热导、预紧力和热挠度 |
| 夹层水冷 | CAFe LIT-006 | 受热内锥→薄壁→夹层高速水流 | 紧贴受热壁背面 | 总功率移除能力强，热阻短 | 高流速、焊缝、腐蚀、压降和水活化 |
| 双壁隔离冷却 | SNS LIT-008 | 内壁→铜丝导热桥→外壁→水 | 水只接触外壁 | 真空—水双重隔离、氦检漏、失氦仍可导热 | 结构复杂，导热桥和双壁制造可靠性 |

## 3. 控制参数不是同一组

### 3.1 远端导热冷却

重点参数：

- 挡块到水路的等效导热热阻；
- 运动机构和波纹管的温度；
- 温升导致的位置误差；
- 水路距束流中心对活化的影响。

适合热负荷较低、真空运动和辐射约束强的设备。

### 3.2 外置冷却管

重点参数：

- 管—基体接触压力；
- 热接触导率；
- 螺栓预紧和烘烤后松弛；
- 管路独立承压；
- 自重与热挠度叠加。

适合要求准直颚可制造、可更换，并对几十微米变形敏感的设备。

### 3.3 夹层水冷

重点参数：

- 局部水速和水力直径；
- 壁面热流密度和沸腾裕度；
- 压降、泵功和流量均匀性；
- 薄壁应力、焊缝和腐蚀；
- 失流后的温升速度。

适合连续吸收几十至数百千瓦总功率的固定结构。

### 3.4 双壁隔离冷却

重点参数：

- 内外壁厚度和压差；
- 导热桥数量、接触和冗余；
- 氦气压力和泄漏检测灵敏度；
- 外壁局部水冷能力；
- 失氦、导热桥失效和外侧断水的组合工况。

适合真空—水边界后果严重、需要在线检漏和容错的结构。

## 4. 对当前设备选型的判断顺序

1. **水能否允许靠近束流区？**
   - 若活化、泄漏或真空后果不可接受，优先考虑远端水路或双壁隔离。

2. **设备是否需要运动或调节？**
   - 可动结构通常不适合复杂内置夹层流道，应优先考虑远端导热或柔性外置管路。

3. **总功率和局部热流密度多大？**
   - 总功率高且持续运行时，夹层水冷或近壁内流道更有优势。

4. **允许多大热变形？**
   - 若有效孔径容差为几十微米，外置管的接触热导和结构刚度必须作为首要指标。

5. **真空与水之间是否允许单点失效？**
   - 若不允许，双壁、监测夹层或双层密封应成为概念设计输入。

6. **结构是否需要远程维护？**
   - 管路接口、焊缝位置、屏蔽条件和可更换模块必须与冷却架构同步确定。

## 5. 建模层级建议

### 一级：快速热阻模型

用于比较架构，不追求细节：

`T_hot ≈ T_water + Q(R_wall + R_contact + R_conv)`

主要用于识别：

- 是壁体导热控制；
- 是接触热阻控制；
- 还是水侧换热控制。

### 二级：稳态共轭传热/等效换热

用于确定：

- 流量和局部换热；
- 峰值温度；
- 壁面温度及沸腾裕度；
- 接触热导敏感性。

### 三级：热—结构与事故瞬态

用于校核：

- 热挠度和有效孔径；
- 螺栓预紧与界面失压；
- 断流、失氦、导热桥失效；
- 整束误入射和联锁允许时间。

## 6. 当前可直接形成的设计输入表

后续评估现有方案时，至少需要收集：

| 类别 | 必要输入 |
|---|---|
| 热源 | 总沉积功率、三维分布、正常/偏移/事故时间历程 |
| 几何 | 受热壁厚、冷却距离、流道尺寸、材料界面 |
| 水力 | 流量、入口温度、压力、压降、局部流速 |
| 界面 | 接触方式、热导范围、预紧力、焊接/钎焊状态 |
| 结构 | 约束、安装方向、允许变形、真空与内压 |
| 保护 | 切束时间、允许脉冲数、流量/压差/温度联锁 |
| 运维 | 活化水、检漏、排水、拆装和远程维护 |

## 7. 当前结论

不能脱离设备功能直接说某一种冷却结构“最好”。当前四类架构的核心区别是：

- CSNS：为运动和活化让出空间；
- CERN：用装配界面换取制造灵活性；
- CAFe：用近壁高速水流处理高连续功率；
- SNS：用双壁和监测夹层换取真空—水安全冗余。

最终方案应由热负荷、几何稳定性、真空后果和维护方式共同选定。
