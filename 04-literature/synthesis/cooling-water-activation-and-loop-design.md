## 1. 核心结论

冷却回路同时承担三类功能：

1. 移走热量；
2. 隔离真空与水边界；
3. 携带并迁移放射性核素。

因此，回路设计不能只闭合流量、压降和温升，还必须闭合：

> 束损源项 → 水中粒子通量 → 核素生成 → 回路输运与衰变 → 局部剂量 → 净化、屏蔽和维护。

## 2. 两类主要源项

### 2.1 水分子活化

由水中氧受到高能质子和中子照射产生，重点包括：

- 长寿命：³H、⁷Be、¹⁴C；
- 短寿命：¹¹C、¹³N、¹⁵O、¹⁴O、¹⁰C、¹⁶N等。

³H通常难以由常规离子交换去除；⁷Be及多数带电离子可通过净化系统去除。

### 2.2 腐蚀产物

管路、换热器和设备材料释放的金属离子或颗粒进入水中后形成：

- Mn、Co、Sc、Fe、Zn、Na等活化产物；
- 树脂床、过滤器和低流速区的局部沉积源项。

因此，材料耐腐蚀性和水化学控制具有直接的辐射防护价值。

## 3. 回路时间参数

短寿命核素活度由以下时间共同决定：

- `tᵢᵣ`：水在受照部件内停留时间；
- `t_c`：水从受照部件到机房/水箱的输运时间；
- `T`：完整循环周期。

设计含义：

- 增大从受照区到人员区的输运时间，可利用核素自然衰变降低机房剂量；
- 循环周期过短，短寿命核素在回路中更容易建立较高平衡活度；
- 水箱、衰变罐和长管段的位置不只是水力问题，也影响辐射源项分布。

## 4. 对当前设备的回路设计要求

### 热工侧

- 流量、流速、压降、入口/出口温度；
- 局部壁温和沸腾裕度；
- 断流和部分堵塞工况。

### 辐射侧

- 受照水体积及其质子/中子通量；
- ³H、⁷Be、¹¹C、¹³N、¹⁵O等源项；
- 腐蚀产物活化；
- 泵、换热器、水箱、阀门和树脂床剂量；
- 停束后访问等待时间。

### 运维侧

- 取样、排水、补水和泄漏处理；
- 树脂及过滤器远程更换；
- 活化水暂存和排放监测；
- 局部屏蔽和人员工作时间限制。

## 5. 四种冷却架构下的活化关注点

| 架构 | 活化关注点 |
|---|---|
| 远端导热冷却 | 水路远离束流可降低直接活化，但导热路径更长 |
| 外置冷却管 | 管路位置和屏蔽决定水中粒子通量，接触热阻仍需控制 |
| 夹层近壁水冷 | 换热能力强，但水最接近束流，活化与泄漏后果更突出 |
| 双壁隔离冷却 | 可降低真空进水风险，但外侧水仍可能活化 |

## 6. 当前设备的最小输入表

| 类别 | 必需参数 |
|---|---|
| 束流损失 | 位置、能量、功率、空间分布、时间结构 |
| 水体 | 受照体积、材料界面、距束流距离、屏蔽 |
| 回路 | 流量、`tᵢᵣ`、`t_c`、`T`、水箱和泵位置 |
| 材料 | 管路和设备材质、腐蚀率、水化学 |
| 净化 | 树脂类型、去除效率、更换周期、废物量 |
| 辐射 | 核素清单、浓度、总活度、管表面剂量、停机衰减 |
| 运维 | 访问区域、允许剂量、屏蔽、远程操作和排放路径 |

## 7. 设计判断

当前阶段不必立即完成精细水活化计算，但概念设计中必须预留：

- 独立水回路；
- 活化水取样与监测；
- 局部屏蔽和远程维护空间；
- 树脂/过滤器更换位置；
- 停束后等待时间和排水策略。

若冷却水靠近主要束损区，水活化应与热工和结构设计同步开展，而不是在设备定型后追加。
