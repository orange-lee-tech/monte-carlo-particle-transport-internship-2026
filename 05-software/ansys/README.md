# Ansys / Fluent 学习记录

本目录用于记录 Ansys 相关软件的安装、配置、学习和案例运行过程。

## 需要向老师确认的问题

1. 是否确认为 Ansys？
2. 需要安装哪个模块？
   - Fluent
   - Workbench
   - CFX
   - Mechanical
   - 其他模块
3. 使用单位许可证还是学生版？
4. 是否有指定教程或案例？
5. 主要服务于热工流体方向，还是与其他仿真任务相关？

## Ansys/Fluent 基本学习路线

1. 软件界面认识；
2. 几何建模或导入；
3. 网格划分；
4. 材料与物性设置；
5. 边界条件设置；
6. 求解器设置；
7. 残差与收敛判断；
8. 后处理：速度场、压力场、温度场、热流密度等。

## 当前优先目标

先完成软件安装与一个基础案例跑通，不急于复杂建模。
