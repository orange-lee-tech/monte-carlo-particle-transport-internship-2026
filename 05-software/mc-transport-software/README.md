# 蒙特卡洛粒子输运软件调研

本目录用于整理蒙特卡洛粒子输运相关软件或程序框架的调研记录。

## 可调研对象

- MCNP
- Geant4
- OpenMC
- FLUKA
- PHITS
- 其他单位或课题组相关程序

## 调研维度

| 维度 | 说明 |
|---|---|
| 软件定位 | 面向核工程、医学物理、高能物理、屏蔽计算等 |
| 是否开源 | 开源/商业/受限分发 |
| 主要粒子类型 | 中子、光子、电子、质子等 |
| 几何建模方式 | 输入卡、脚本、CAD 接口等 |
| 材料定义方式 | 核素、密度、截面库等 |
| 源项定义 | 点源、面源、体源、能谱、方向分布等 |
| 计数器/输出 | 通量、剂量、能量沉积、反应率等 |
| 学习难度 | 入门成本、文档质量、案例数量 |
| 与本实习关系 | 是否适合作为调研或学习对象 |

## 当前目标

先建立软件对比框架，不急于深入每个软件。重点理解“粒子输运软件一般需要输入什么、输出什么、计算流程是什么”。
