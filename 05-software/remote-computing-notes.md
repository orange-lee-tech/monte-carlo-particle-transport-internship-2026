# 远程计算与超算桌面记录

更新时间：2026-07-07

## 1. 当前条件

用户在东江实验室有 VPN 节点，可以接入超算中心并建立远程桌面。

远程桌面可以打开多个程序窗口，后续用于运行 Fluent 和 FLUKA 可能比个人电脑更快。

## 2. 当前用途判断

远程计算资源的主要价值：

- 运行 Fluent 计算；
- 运行 FLUKA 计算；
- 打开多个程序窗口；
- 减轻个人电脑计算压力；
- 便于后续处理较大算例。

## 3. 使用优先级

当前阶段仍以本地熟悉软件界面和最小案例为主。

当出现以下情况时，优先考虑使用远程桌面或超算资源：

- 本地电脑运行太慢；
- 计算文件包规模较大；
- Fluent 需要长时间迭代；
- 需要同时打开多个程序窗口；
- 后续涉及 FLUKA 计算。
