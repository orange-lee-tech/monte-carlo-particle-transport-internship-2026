# 05-software：软件学习与操作记录

本目录用于记录实习期间涉及的软件安装、配置、学习流程、操作步骤和问题解决过程。

## 子目录说明

- `ansys/`：Ansys、Fluent、Workbench、CFX、Mechanical 等相关记录。
- `mc-transport-software/`：蒙特卡洛粒子输运软件调研，例如 MCNP、Geant4、OpenMC 等。

## 记录原则

软件学习最重要的是留下可复现步骤，建议记录：

1. 软件名称和版本；
2. 安装来源与许可证情况；
3. 电脑系统环境；
4. 安装步骤；
5. 报错信息；
6. 解决方法；
7. 第一个成功运行的案例；
8. 后续需要学习的功能。

## 注意事项

不要上传许可证文件、账号密码、服务器地址、单位内部路径等敏感内容。
