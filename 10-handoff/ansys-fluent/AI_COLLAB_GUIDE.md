# 与 AI 协作指南

AI 在本项目中的最佳角色不是“替你点 Fluent”，而是：读终端、维护上下文、设计低风险 A/B 试验、区分故障层级，并帮助把结论沉淀到日志和仓库。

## 推荐提问模板

```text
这是新的 ANSYS 接手对话。

当前软件：Fluent Meshing 2021 R1
当前主线：正式准直器几何 → 流体域 → 体网格 → UDF → Solver
当前阶段：[做到哪]
刚完成：[最近成功动作]
当前错误：[贴完整终端输出]
本轮目标：只解决 [一个问题]

限制：
1. 一次只给一个主操作；
2. TUI 命令说明只读还是会修改网格；
3. 不随意改变已验证基线；
4. 若根因属于 CAD，请明确停止 Fluent 调参；
5. 用“看到什么 → 输入什么 → 正常结果 → 异常结果”指导。
```

## 提问技巧

- 贴完整 terminal output，不要只贴最后一行错误。
- 明确上一步做了什么，避免 AI 对当前状态判断错误。
- 主动限定“本轮只解决一个问题”，减少并行试错。
- 要求 AI 标注命令风险：只读 / 标记 / 修改网格 / 破坏性。
- 对结论要求证据：数值、Zone ID、截图、A/B 结果。
- 新对话先给交接摘要，不依赖聊天窗口的漫长历史。

## 推荐阶段交接模板

```text
这是新的阶段对话。请先基于以下交接摘要继续工作：
1. 当前主线：
2. 已完成：
3. 仓库已更新：
4. 当前待办：
5. 禁止修改：
6. 本轮目标：
```

## 低信息量提问示例

不推荐：

> Fluent 报错了怎么办？

至少应提供：软件版本、当前阶段、完整输出、当前参数、上一操作、本轮目标。
