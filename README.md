```text

├── 00-admin/                 # 当前任务、规则和阶段交接

│   ├── references/           # 原始文献证据源
│   ├── deep-reading/         # 人工精读和直接继承基线
│   ├── notes/                # 外部文献机器辅助结构化笔记
│   └── synthesis/            # 跨文献专题综合
```

编号目录只负责工程管理分类。`fluka_to_c_translation/`是可执行代码包，保留软件包式命名，不参与管理目录编号。

已完成的结构收口：

- `02-weekly-review/`并入`01-daily-log/weekly-review/`；
- `05-reference/`并入`04-literature/deep-reading/`；
- 文献索引、精读规则和工程继承状态统一由`04-literature/`管理。

## 文献使用原则

文献分为两类：

- **直接继承基线**：帅文文论文及其模型、脚本和数据，当前优先吃透并复现；
- **外部方法支撑**：PSI、CERN、SNS、J-PARC、CSNS等文献，在基线继承后用于方法借鉴、风险预警和独立拓展。

外部文献参数不得直接照搬。当前设备参数应由本地粒子输运、流体与热结构模型确定。

## 记录原则

- 区分“已阅读、已运行、已验证、待核实”；
- 重要结论可追溯到PDF、代码、日志或验证报告；
- 聊天用于即时协作，长期结论写入GitHub；
- 课题组已有成果与个人新增成果明确区分；
- 未公开资料遵守保密和脱敏要求。
