# 自主实习工程管理仓库

本仓库用于管理 2026 年暑期自主实习期间的学习、调研、软件使用、日志记录、报告撰写与答辩准备材料。

## 一、当前实习主线

当前任务已具体化为：**学习 Ansys，服务后续热工流体与热结构计算工作**。

用户专业方向为能源动力热工方向，因此现阶段主线与专业背景直接相关。后续工作可能延续帅文文《CiADS 缪子源靶后高功率准直器设计》中的相关计算，重点可能包括：

- Ansys Workbench 基础流程；
- Fluent / CFX 流动与换热计算；
- Mechanical 稳态热分析与热应力分析；
- 冷却流道、温度场、压力场、速度场和等效应力后处理；
- 将粒子输运或能量沉积结果转化为热源项输入 Ansys。

原“蒙特卡洛粒子输运程序开发调研”暂作为课题背景和上游计算背景保留，不再作为当前唯一执行主线。

## 二、实习时间

2026 年 7 月 6 日至 2026 年 8 月 28 日，为完整工作周期，共 8 周。

## 三、仓库定位

本仓库不是单纯代码仓库，而是一个长期可追踪、可扩展的实习工程管理仓库，主要用于：

1. 记录每日实习日志；
2. 管理每周计划、周总结与阶段性成果；
3. 整理 Ansys、热工流体、热结构分析和相关基础知识；
4. 保留蒙特卡洛、粒子输运、能量沉积等上游背景知识；
5. 记录软件安装、案例学习、计算流程和问题解决过程；
6. 沉淀文献阅读笔记、问题清单、图表素材与报告材料；
7. 为实习报告与开学 PPT 答辩提供可复用素材。

## 五、使用原则

### 1. 每天一个 Markdown 日志

实习周期为 7.6—8.28，建议每天对应一个日志文件。最终日志文件数量按完整周期累计。

日志要求：格式简单、内容具体、不堆字数、可追溯。

每篇日志至少回答：

- 今天做了什么；
- 学到了什么；
- 遇到什么问题；
- 明天做什么。

### 2. 当前主线优先级

近期优先级为：

1. 学会 Ansys 基础操作；
2. 明确具体模块：Fluent、Workbench、Mechanical、CFX 或耦合流程；
3. 理解帅文文论文中热结构仿真与冷却计算的任务关系；
4. 复现或学习基础热工流体算例；
5. 再逐步回看粒子输运、能量沉积和上游热源项来源。

### 3. 先记录，再整理

刚开始不追求完美排版。先把学习过程、软件截图、问题、术语解释和老师要求记录下来，后期再整理成报告和 PPT。

### 4. 注意保密与合规

涉及以下内容时，不上传或进行脱敏处理：

- 实习单位内部资料；
- 未公开实验数据、计算数据或工程文件；
- 软件许可证、账号、服务器地址、内部路径；
- 老师或单位明确要求不得外传的内容。

### 5. 文件命名尽量稳定

建议使用日期、周次、主题组合命名，例如：

```text
2026-07-06.md
week01-review.md
ansys-workbench-basics.md
fluent-heat-transfer-case.md
shuai-wenwen-thesis-brief.md
```
