# 蒙特卡洛粒子输运自主实习工作仓库

本仓库用于管理 2026 年暑期自主实习期间的学习、调研、软件使用、日志记录、报告撰写与答辩准备材料。

## 一、实习主题

**蒙特卡洛粒子输运程序开发调研**  
以调研为主，掌握蒙特卡洛方法理论基础，学习使用现有软件；同时结合能源与动力工程专业背景，适当拓展热工流体仿真与 Ansys/Fluent 等工程软件学习。

## 二、实习时间

2026 年 7 月 6 日至 2026 年 8 月 28 日，共 8 周。

## 三、仓库定位

本仓库不是单纯的代码仓库，而是一个长期可追踪的实习工程管理仓库，主要用于：

1. 记录每日实习日志；
2. 管理每周计划、周总结与阶段性成果；
3. 整理蒙特卡洛方法、粒子输运、核科学基础与热工流体基础知识；
4. 记录 Ansys/Fluent 及粒子输运相关软件的安装、学习和算例过程；
5. 沉淀文献阅读笔记、问题清单、图表素材与报告材料；
6. 为实习报告与开学 PPT 答辩提供可复用素材。

## 五、使用原则

### 1. 每天都要留痕

实习期间建议每天至少提交一次日志，哪怕只记录三件事：

- 今天做了什么；
- 遇到了什么问题；
- 明天准备做什么。

### 2. 先记录，再整理

刚开始不追求完美排版。先把学习过程、软件截图、问题、术语解释和老师要求记录下来，后期再整理成报告和 PPT。

### 3. 注意保密与合规

涉及以下内容时，不上传或进行脱敏处理：

- 实习单位内部资料；
- 未公开实验数据、计算数据或工程文件；
- 软件许可证、账号、服务器地址、内部路径；
- 老师或单位明确要求不得外传的内容。

### 4. 文件命名尽量稳定

建议使用日期、周次、主题组合命名，例如：

```text
2026-07-06.md
week01-review.md
fluent-installation-notes.md
monte-carlo-random-sampling.md
```

## 六、近期工作重点

第 1 周重点不是做出复杂成果，而是完成以下基础建设：

1. 明确老师交代的实习任务；
2. 确认需要安装和学习的软件，尤其是 Ansys/Fluent；
3. 建立实习日志记录习惯；
4. 初步学习蒙特卡洛方法、粒子输运和热工流体基础术语；
5. 形成第 1 周计划和问题清单。

## 七、长期输出目标

到实习结束时，本仓库应能支撑以下材料：

- 学校要求的全过程实习日志；
- 实习单位要求的实习报告；
- 中南大学要求的实习报告；
- 开学 PPT 答辩材料；
- 后续继续学习蒙特卡洛粒子输运或热工流体仿真的个人知识库。
