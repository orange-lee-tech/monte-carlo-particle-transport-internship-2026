# 自主实习工程管理仓库

本仓库用于管理 2026 年暑期实习期间的文献继承、粒子输运—热工耦合、Ansys 计算、验证记录、日志与汇报材料。

## 一、当前主线

当前工作已从软件入门进入已有模型继承与验证阶段：

```text
帅文文论文与原始计算资料
→ 理解束流、能量沉积和热工计算链
→ 恢复 FLUKA → C 数组 → Fluent UDF 接口
→ 验证数据、单位、坐标映射和能量守恒
→ 复现论文锚点工况
→ 在可靠基线上开展独立拓展与结构优化
```

近期优先级：

1. 完整继承帅文文已有工作和计算接口；
2. 解释当前热源映射功率差异，完成物理与数值验证；
3. 建立可复现的论文锚点工况；
4. 在此基础上再系统精读外部文献，支撑开创性拓展；
5. 最后进入新结构、新工况和工程优化。

## 三、文献使用原则

文献分为两类：

- **直接继承基线**：帅文文论文及其原始模型、脚本和数据，当前必须优先吃透；
- **外部方法支撑**：PSI、CERN、SNS、J-PARC、CSNS 等文献，用于方法借鉴、量级检查和风险预告。

外部文献中的尺寸、流速、温度、应力和联锁时间不得直接照搬。当前设备参数应由本地粒子输运、流体与热结构计算确定。

## 四、记录原则

- 重要结论必须能追溯到原始文件、日志或验证记录；
- 聊天只用于即时协作，长期成果写入 GitHub；
- 明确区分“已计算”“已验证”“已人工阅读”和“仅完成机器结构化整理”；
- 不把已有课题组成果包装为个人新成果；
- 涉及未公开资料时遵守保密和脱敏要求。

## 五、长期输出

- 热工设计方法库与风险工况清单；
- 组会、实习报告和开学答辩材料。
