# 09-archive：历史归档区

本目录保存仍有参考价值、但已经退出现役入口的材料。归档的目的，是让主目录只留下当前有效文件，而不是删除所有历史痕迹。

## 当前归档结构

- `handoffs/`：实习早期阶段交接；
- `planning/`：早期周计划；
- `reports/`：已被最终报告结构替代的旧提纲；
- `presentation/`：已被最终 PPT 信息架构替代的旧提纲；
- `publishing/wechat-articles/`：曾用于微信公众号公开版的模板与排版规范。

## 使用规则

- 当前状态、执行入口不得只存在于归档区；
- 归档文件不再作为“最新版本”引用；
- 若某文件只是空占位、通用模板或无事实价值，则直接删除，不为归档而归档。
