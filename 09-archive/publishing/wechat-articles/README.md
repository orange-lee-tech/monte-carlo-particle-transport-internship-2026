# 微信公众号文章模板与使用说明

本目录用于保存实习周报公开发布版的写作模板、Word 视觉规范和脱敏规则。

该模板适合以下内容：

- 实习周报公开版；
- 科研学习手记；
- 软件学习与工程实践复盘；
- 面向本科生的技术科普文章。

## 目录内容

```text
wechat-articles/
├── README.md                 # 使用说明与发布流程
├── word-style-guide.md       # Word 排版和视觉设计规范
└── article-template.md       # 可直接复制的文章内容模板
```

## 推荐使用流程

### 1. 先完成内部周报

内部周报以事实完整、数据可追溯为第一原则，可以包含具体软件版本、参数、文件关系和验证结果。

### 2. 复制公开文章模板

复制 `article-template.md`，将标题、引言、章节和结语替换为本周内容。公开文章不应直接复制内部周报，而应重新组织为：

```text
本周遇到的问题
→ 采取的方法
→ 形成的认识
→ 尚未解决的边界
→ 下一阶段方向
```

### 3. 完成信息脱敏

发布前逐项检查：

- 删除未公开的单位、课题组和人员姓名；
- 删除仓库地址、账号、内部网络及远程计算入口；
- 删除本地磁盘路径、服务器路径和个人文件夹名称；
- 将具有唯一识别性的工况名、文件名和函数名改为通用描述；
- 未公开的精确参数、温度、功率和结构指标原则上改为量级或趋势；
- 删除截图中的用户名、路径、设备编号和内部项目名称；
- 区分公开文献结论、课题组已有成果和个人学习进展；
- 不把“程序成功运行”写成“物理结论已经得到验证”。

### 4. 按视觉规范排版

在 Word 中按照 `word-style-guide.md` 设置：

- 封面色块；
- 关键词标签；
- 开篇引语；
- 编号章节；
- 流程图式表格；
- 经验卡片和技术小词典；
- 页眉、页码和统一留白。

模板的核心风格是：

> 清爽、克制、具有工程感；重点突出，但不过度装饰。

### 5. 进行发布前检查

最终文件至少检查一次：

1. 标题层级是否清楚；
2. 是否存在孤行、表格断裂或页面留白异常；
3. 中英文、数字与单位之间的空格是否统一；
4. 所有图表是否能脱离上下文被理解；
5. 文章是否明确说明当前工作边界；
6. 是否仍含敏感路径、姓名或内部参数。

如由程序生成 Word，应执行：

```text
生成 DOCX
→ 转为 PDF/页面图片
→ 逐页检查
→ 修正布局
→ 再次导出
```

## 文件命名

推荐格式：

```text
公众号文章_第X周_文章短标题.docx
```

示例：

```text
公众号文章_第一周_从任务模糊到模型跑通.docx
```

## 内容版本管理

同一篇文章建议区分三种状态：

```text
内部周报：保留完整事实和参数
公开初稿：完成内容重写和脱敏
发布终稿：完成排版、校对和视觉检查
```

公开文章不替代每日实习日志和内部周报。它的作用是将真实工作转化为公众能够理解、且不泄露内部信息的学习叙事。
