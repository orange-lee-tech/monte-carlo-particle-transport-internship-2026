## 5. 当前形成的设计认识

当前文献链已形成六条可复用主线：

1. 通过孔型、束斑和多级结构重塑能量沉积分布；
2. 冷却方案要同时考虑真空、屏蔽、活化和维护；
3. CFD和界面参数应通过可控试验校核；
4. 高功率设备需要从仿真、制造到分级运行的工程闭环；
5. 多材料装配中，接触热导、螺栓预紧和自重可能比峰值温度更早控制几何稳定性；
6. 真空与水之间可通过双壁、监测夹层和独立导热桥建立安全冗余。

冷却结构当前分为四类：

- 远端导热冷却；
- 外置冷却管；
- 夹层近壁水冷；
- 双壁隔离与检漏冷却。

## 6. 文献处理原则

- 原始文献作为不可修改的证据源，不直接在原文件内插入标签。
- GitHub 主要保存索引、页码地图、阅读笔记、专题综合和分享材料，不依赖聊天缓存。
- 不默认将整篇文献全文转换为 Markdown；长文档只抽取目录、关键章节、重要图表和高价值数据。
- 所有技术结论必须保留原文页码、章节、图号或表号。
- 明确区分文献事实、我们的工程理解和待补充问题。
- 以最终设备热工设计参考价值为主，不对论文作无关的过度挑错。
