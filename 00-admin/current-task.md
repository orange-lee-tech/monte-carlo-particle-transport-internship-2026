## 2. 新阶段主线

后续工作主线转向：

> 面向缪子束流踢坏区 / 高功率准直吸收结构的热工设计与热应力计算。

背景理解：打靶后会产生部分不干净或偏离要求的缪子束流，需要通过准直/吸收结构将坏区束流剔除。在吸收过程中，粒子能量沉积和动量变化等效为结构内部热源，导致温升、热应力和变形。当前任务是围绕该热源开展热工设计。

## 3. 设计目标

| 目标 | 当前要求 / 判断 |

| 功能目标 | 满足剔除坏区束流的要求 |

| 结构目标 | 控制热应力和热变形在允许范围内 |
| 材料 | 铜 / 铜基结构为主 |
