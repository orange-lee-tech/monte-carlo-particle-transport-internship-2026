## 5. 文献处理原则

- 原始 PDF 作为不可修改的证据源，不直接在 PDF 内插入标签。
- GitHub 主要保存索引、页码地图、阅读笔记、专题综合和分享材料，不依赖聊天缓存。
- 不默认将整篇 PDF 全文转换为 Markdown；长文档只抽取目录、关键章节、重要图表和高价值数据。
- 所有技术结论必须保留 PDF 页码、章节、图号或表号。
- 明确区分：文献事实、作者假设、我们的判断、待确认问题。
- 未完成交叉核验的结论不得写成确定事实。
