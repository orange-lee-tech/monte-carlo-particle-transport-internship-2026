# 当前任务说明

更新时间：2026-07-07

## 1. 当前主线

现阶段实习任务已具体化为：

> 以 Ansys Workbench 为入口，重点学习 Fluent，服务后续热工流体与热结构计算工作。

用户专业方向为能源动力热工方向，因此当前任务与专业背景直接对应。

## 2. 软件与模块判断

目前打开的软件界面显示为 Workbench，启动加载界面显示为 Ansys。当前判断如下：

| 对象 | 当前定位 |
|---|---|
| Ansys | 软件平台总称 |
| Workbench | 工程项目入口与模块集成平台 |
| Fluent | 当前重点学习模块，用于热工流体计算 |
| Mechanical | 后续可能涉及，用于热分析、结构应力或热结构耦合 |
| 计算文件包 | 近期核心对象，先跑通，再理解，再修改 |

## 3. 背景任务

原始行政主题为：

> 蒙特卡洛粒子输运程序开发调研——以调研为主，掌握蒙特卡洛方法理论基础，学习使用现有软件。

根据最新情况，该主题更适合作为课题背景或上游计算背景保留。后续实际执行主线应转向 Ansys Fluent 热工流体计算，并根据计算文件包情况逐步理解其与热结构、能量沉积和束流偏移工况之间的关系。

## 4. 与帅文文论文的关系

师姐提供的帅文文学位论文《CiADS 缪子源靶后高功率准直器设计》摘要显示，论文使用 FLUKA、G4beamline 和 ANSYS 完成高功率准直器结构设计，并建立热结构仿真模型。

结合老师交代和已提供的计算文件包，当前判断：后续工作大概率是延续该论文中的计算工作，可能包括基础案例跑通、文件包复现、Fluent 热工流体计算、冷却流道分析、热结构分析和后续工况扩展。

## 5. 当前任务分层

| 阶段 | 目标 | 说明 |
|---|---|---|
| 第 1 阶段 | 会打开、会识别 Workbench 项目结构 | 不急着改参数，先看懂文件包由哪些模块组成 |
| 第 2 阶段 | 跑通基础案例 | 学会 Fluent 基本流程：网格、边界条件、求解、后处理 |
| 第 3 阶段 | 跑通师姐留下的计算文件包 | 先复现，不主动大改 |
| 第 4 阶段 | 读懂文件包设置 | 明确几何、网格、材料、边界条件、入口流速、热源项、残差和结果 |
| 第 5 阶段 | 延续计算 | 根据老师要求改变工况或参数，开展进一步计算 |
